# ScreenClip · 截图助手

一个常驻 macOS 菜单栏的轻量截图工具：框选后直接复制、滚动长截图，以及在原截图位置显示译文。

## 下载与安装

[下载安装包（DMG）](https://github.com/peake166/screenclip/releases/latest/download/ScreenClip-macOS-universal.dmg) · [下载压缩包（ZIP）](https://github.com/peake166/screenclip/releases/latest/download/ScreenClip-macOS-universal.zip) · [全部版本](https://github.com/peake166/screenclip/releases)

打开 DMG，将「截图助手.app」拖入「Applications / 应用程序」，再从应用程序中打开。ZIP 解压后同样将应用移入「应用程序」。安装包内附首次使用说明，无需 Xcode。

**当前公开包未经 Apple 公证。** 首次打开时 macOS 可能拦截；确认来自本仓库后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在「系统设置 → 隐私与安全性」中为截图助手选择「仍要打开」。无需关闭 Gatekeeper 或运行解除隔离的命令。若系统明确报告恶意软件或禁止运行，请停止安装。

通用包包含 Apple Silicon（arm64）和 Intel（x86_64）架构。当前已在 Apple Silicon Mac 验证，尚未在 Intel Mac 实机验证。下载页附 SHA-256 校验值。安装包不包含 API Key 或任何个人配置，云翻译需自行填写密钥。

## 功能

- **截图并复制**：框选区域后写入剪贴板，切换到其他应用即可粘贴。
- **滚动截图**：框选可滚动内容，缓慢滚动后完成并复制长图；未接上的内容会提示处理。
- **原位截图翻译**：本地识别文字，在截图位置覆盖译文，支持查看原文和按 Esc 退出。
- **翻译服务**：Apple 系统翻译、硅基流动、智谱 GLM；云服务需要使用自己的 API Key，可选择或填写模型。
- **模型测速**：用固定短文逐个比较已接入服务的内置模型及当前自定义模型，查看耗时、译文和失败原因，直接选用成功的模型；用户点击后才发送请求。
- **自定义全局快捷键**，支持清除和恢复默认。
- **剪贴板历史**：开启后本地保存文字、图片和富文本，支持搜索、分类预览、置顶、暂停、排除应用和自动清理；回车直接粘贴到原输入框，⌘回车仅复制。
- **登录时启动**，关闭主窗口后继续在菜单栏运行。

## 使用

需要 macOS 14 或以上。系统翻译需要 macOS 15 或以上，支持的语言与设备由系统决定，首次使用可能需要下载语言。macOS 14 可使用云翻译。

1. 将应用放入「应用程序」后运行，在「系统设置 → 隐私与安全性 → 录屏与系统录音」允许截图助手；按系统提示重新打开应用。
2. 通过菜单栏或快捷键开始截图。在主窗口的「快捷键」中修改按键，在「翻译设置」中选择服务并保存自己的密钥。
3. 需要自动运行时，在主窗口开启「登录时启动」。关闭主窗口不会退出应用，菜单栏的「退出截图助手」才会结束运行。

新安装的默认快捷键如下，已有用户的自定义设置会保留：

| 操作 | 默认快捷键 |
| --- | --- |
| 截图并复制 | ⌃⌥⌘4 |
| 滚动截图 / 完成 | ⌃⌥⌘5 |
| 截图翻译 | ⌃⌥⌘6 |
| 剪贴板历史 | ⇧⌘V |

升级保留已有快捷键和翻译 API 设置。剪贴板历史初次处于暂停状态，点击窗口右上角「已暂停」后开始记录，只保存之后新复制的内容，不导入启动前或暂停期间的剪贴板。每次打开会清空搜索和筛选并定位到最新项。方向键选择，回车或双击直接粘贴到原应用的输入框，⌘回车仅复制，⇧⌘P 置顶或取消置顶，⌘K 打开操作菜单，Esc 关闭。自动粘贴需要在「系统设置 → 隐私与安全性 → 辅助功能」允许截图助手；未授权时保留复制结果并提示手动粘贴。也可在剪贴板偏好中将回车改为仅复制或优先粘贴纯文本。

普通历史默认保留 30 天、最多 5000 条、内容总上限 1 GiB，单条上限 16 MiB；时间、条数或空间先到限制时清理最早的普通记录。时间从最后一次复制或使用起计算。置顶长期保留，取消置顶后重新计时；清空普通历史保护置顶，删除全部（含置顶）需单独确认。置顶占满空间时提示清理，不会自动删除置顶。偏好设置可调整时间、条数、空间与排除应用。图片按原始数据保存，缩略预览不影响粘贴质量；搜索检索文字和来源应用，长文本只索引开头部分，粘贴保留完整原文。

滚动截图时保持选区和窗口位置不变，缓慢滚动并观察段数增加；再次按相同快捷键或点击完成后复制，Esc 取消。长图有内存保护上限，达到上限时可复制本段，再继续截图。受保护窗口、动画、重复内容或页面布局变化可能导致采集或拼接失败，本项目不保证绕过应用的截图保护。

## 隐私与密钥

- 本仓库不附带 API Key、个人设置、钥匙串、签名证书或真实截图记录。
- API Key 保存在本机 macOS 钥匙串，不写入源码或普通偏好设置；可在翻译设置中删除。
- 文字识别通过 Apple Vision 在本机完成。使用云翻译时，将识别出的文字发送给所选服务商，不上传截图图片。请避免翻译不希望发送给服务商的敏感内容。
- 系统翻译使用 Apple Translation，由系统管理语言资源；本项目没有自己的翻译服务器。
- 未开启剪贴板记录时不保存截图历史。开启后，历史在本机 Application Support 的独立目录使用 AES-256-GCM 加密保存，独立密钥存放在本机钥匙串，不上传至 GitHub 或云翻译服务；旧版历史成功加密迁移后才移除原明文文件；普通截图仍进入系统剪贴板。系统和第三方剪贴板管理工具也可能保存剪贴板内容。
- 历史跳过已标记为敏感、临时或自动生成的剪贴板内容，默认排除常见密码管理器。普通文本中的密码和 API Key 仍可能被记录；可暂停记录、排除来源应用或删除历史。
- 云模型的可用性、限流和费用由服务商决定；内置选项不代表永久免费，调用前请核对服务商规则。

## 从源码构建

需要 Xcode 26 或更新版本及其 macOS SDK，并已选择对应的 Command Line Tools。脚本仅使用系统框架，无需额外安装运行时依赖。

```sh
./build.sh
```

生成的应用位于 `dist/截图助手.app`。默认构建当前机器架构，可将生成的应用移入「应用程序」后运行。签名行为和可选参数见 [build.sh](build.sh)；本项目不提供已公证的发行承诺。自行构建、更换签名或移动应用后，可能需要重新授予屏幕录制权限。

构建与公开包相同的通用架构应用，并使用临时签名：

```sh
SCREENCLIP_UNIVERSAL=1 SCREENCLIP_SIGN_IDENTITY=- ./build.sh
```

```sh
./test.sh
```

测试覆盖拼接、图像与独立剪贴板、快捷键、文字识别、翻译流程和界面布局。云接口测试使用模拟响应，不需要 API Key，也不调用真实云服务。部分测试使用 AppKit、Vision 和原生快捷键，需要 macOS 图形登录会话；测试通过不代表所有第三方应用都能正常截图。

`fixture-web/` 和 `Tests/` 中包含合成测试内容。`Tests/ReadClipboard.swift` 和 `Tests/DailyCaptureFixture.swift` 是可选的手动剪贴板检查工具，不在默认测试中运行；显式运行时会访问系统剪贴板。编译产物、预览、临时诊断和本地配置由 `.gitignore` 排除，请勿将真实截图、密钥或证书加入提交。
